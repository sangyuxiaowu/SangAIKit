# 06. 主题系统、多套配色与样式隔离

`SangAIKit` 拥有一套完全基于 CSS 自定义属性（CSS Variables）与作用域隔离工具类的视觉系统，支持**深色模式（Dark）**、**浅色模式（Light）**、**跟随系统（System）**以及**多套主题色盘实时切换**。

---

## 默认双模式与原项目提取配色

组件库在 `src/assistant.css` 与 `demo/palettes.ts` 中内置了 6 套完整色盘：

1. **曜石靛蓝 · 默认主题 (`default`)**：
   - **深色模式**：采用深邃的曜石石墨黑底（`#11141c`）搭配皇家钴靛蓝强调色（`#4f6ef7`），降低长时间阅读的视觉疲劳并凸显现代工程感。
   - **浅色模式**：采用清透的日光岩白底（`#f8f9fc` / `#ffffff`）搭配高对比度钴蓝强调色（`#3b5bdb`），并为所有顶部横幅卡片、状态徽章与次级按钮提供柔和的日光渐变层次。
2. **松石翠绿 · 原项目配色 (`legacy`)**：
   - 完整提取并保留了原项目的松石深蓝灰深色底（`#0f172a`）+ 翡翠绿强调色（`#10b981`），以及浅色模式下的冰川白底（`#f9fbfd`）+ 钢青蓝强调色（`#1675d1`）。
   - 宿主可通过在容器或组件上设置 `data-palette="legacy"` 或注入对应的 `--sang-ai-*` 变量一键还原原项目风格。
3. **扩展演示色盘**：
   - **星云紫罗兰 (`violet`)**、**珊瑚玫红 (`rose`)**、**流金琥珀 (`amber`)**、**极光青碧 (`cyan`)**，并支持通过自定义拾色器任意覆盖 `--sang-ai-accent`。

---

## 核心 CSS 变量契约 (`--sang-ai-*`)

宿主可在 `:root` 或包裹容器上定义以下 CSS 变量，实时接管助手浮窗、配置中心弹窗与 Portal 预览层的视觉表现：

| 变量名称 | 作用说明 | 深色默认参考值 | 浅色默认参考值 |
| --- | --- | --- | --- |
| `--sang-ai-accent` | 主题核心强调色（按钮、激活态、焦点环、徽章） | `#4f6ef7` | `#3b5bdb` |
| `--sang-ai-accent-strong` | 高亮强调色（悬浮文字、活跃图标） | `#8198fa` | `#2b44b8` |
| `--sang-ai-accent-soft` | 柔和辅助强调色（次级渐变、标签高光） | `#a5b4fc` | `#4c6ef5` |
| `--sang-ai-bg` | 助手浮窗主背景（支持半透明毛玻璃） | `rgba(17, 20, 28, 0.95)` | `rgba(255, 255, 255, 0.96)` |
| `--sang-ai-dialog-bg` | 配置中心模态框主背景 | `#11141c` | `#f8f9fc` |
| `--sang-ai-surface` | 卡片与消息气泡基础表面色 | `rgba(26, 31, 43, 0.82)` | `#ffffff` |
| `--sang-ai-surface-elevated` | 悬浮控件、次级按钮与代码块抬升表面色 | `rgba(36, 43, 59, 0.78)` | `#f2f4f9` |
| `--sang-ai-border` | 容器与卡片主边框色 | `rgba(56, 65, 82, 0.68)` | `#dde3ee` |
| `--sang-ai-text` | 一级标题与正文主文字色 | `#f3f5f9` | `#141923` |
| `--sang-ai-muted` | 辅助说明与次级图标颜色 | `#949eb0` | `#5c667a` |

## 样式作用域隔离机制

为避免污染宿主页面的全局样式或受宿主 CSS Reset 干扰，`SangAIKit` 采用了严格的样式隔离架构：

1. **选择器作用域限定**：`style-build/build-styles.ts` 会将 Tailwind CSS v4 生成的所有工具类自动包裹在 `:where(.cf-ai-panel, .sang-ai-settings, .sang-ai-portal)` 下，输出至 `generated/sang-ai-utilities.css`。
2. **Portal 主题自动同步**：无论是图片大图预览弹窗、删除确认框还是配置中心，均挂载 `.sang-ai-portal` 或 `.sang-ai-settings` 类名并同步 `data-theme` 属性，确保在深浅模式切换时无死角响应。

# 07. 演示工作台使用指南

本演示应用旨在全方位展示 `SangAIKit` 的每一项配置参数、插槽扩展能力与交互细节。你可以通过左侧导航栏在 **「工作区（能力演示台）」** 与 **「帮助文档（Docs 章节阅读器）」** 之间随时切换。

---

## 一、主题色彩与深浅模式体验

1. **顶部快捷切换与色盘矩阵**：
   - 在顶部工具栏或工作区「多套色彩切换」面板中，点击任意色盘卡片（如「曜石靛蓝 · 默认主题」、「松石翠绿 · 原项目配色」等）即可实时切换整套 UI 与 AI 助手的色彩体系。
   - 点击右上角的圆形取色器可自定义任意 HEX 强调色；点击太阳/月亮/显示器图标可在**浅色 / 深色 / 跟随系统**模式间无缝切换。

---

## 二、全能力交互实验室 (Capability Playground)

在工作区的 **「组件能力与交互实验室」** 面板中，你可以实时调节以下四大类设置并立即在右侧 AI 助手浮窗或配置中心里看到效果：

### 1. 界面文案、语言与上下文栏
- **界面语言 (`language`)**：一键在 `中文 (zh)` 与 `English (en)` 之间切换，验证全量组件的国际化表现。
- **场景人设预设**：一键切换「通用工作区助手」、「视觉海报设计助手」、「代码架构审计助手」等预设，实时改变助手的 `title`、`emptyTitle`、`emptyDescription` 与上下文状态栏。
- **上下文状态栏 (`contextTitle` / `contextMeta`)**：可随时开启/关闭助手顶部带呼吸绿点的上下文横幅，并实时修改工作区标题与图层元数据。
- **浮窗形态控制**：支持一键打开/关闭浮窗、切换**最小化胶囊状态**（可在最小化时触发模拟对话，观察胶囊条上的实时工具步骤轮播动效），以及一键切换「标准右侧停靠 / 紧凑小窗 / 宽屏工作台 / 居中浮窗」尺寸预设。

### 2. 插槽与扩展面板开关
- **对话分叉 (`onFork`)**：开启后点击任意 AI 回复下方的分叉图标，立即切出一条带 `(分叉)` 后缀的新会话。
- **视觉多模态开关 (`supportsVision`)**：开启后输入框左下角出现上传图片按钮（支持拖拽/粘贴最多 4 张图片）；关闭后可测试纯文本模型下的「图片已暂存，本条仅发送文字」保护提示。
- **Token 用量环 (`TokenUsageBar`)** 与 **模型切换器 (`ModelControls`)**：可独立开关输入框底部的内联控件。
- **智能抠图扩展页 (`renderBackgroundRemoval`)**：开启后打开 AI 配置中心，你会看到新增的 **「智能抠图」** 标签页，直观演示宿主如何向配置中心注入自定义业务设置面板。

### 3. 本地模拟器与一键场景注入
即使不填写任何第三方 API Key，在默认的 **「本地演示 (`local-demo`)」** 模型下，你也可以勾选丰富的模拟能力：
- **模拟思考推理流 (`Reasoning`)**：在回复前流式输出可展开的 `<Brain /> 思考过程`。
- **模拟多步工具调用链 (`Multi-Tool Chain`)**：依次演示 `read_workspace`、`list_fonts`、`demo_context` 的运行中与完成耗时状态。
- **模拟本地生图 (`Simulated Image Generation`)**：自动生成精美的 SVG/PNG 视觉作品并写入 IndexedDB，生成后可点击预览大图，或进入「历史对话 -> 图片画廊」测试分类筛选与 **「置入工作区」**！
- **模拟轮次上限暂停 (`Continuable Turn`)**：演示达到轮次上限时的暂停提示与「继续」按钮。
- **一键注入全能力演示会话**：点击「注入全功能示例会话」按钮，系统会自动生成包含思考流、工具链、AI 生图作品、过程预览图与参考附件的完整会话及画廊数据，方便立即体验所有高阶功能。
